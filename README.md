# Поиск частых наборов объектов с использованием алгоритма Apriori

## Описание проекта

Программа для поиска частых наборов объектов в наборе данных с использованием алгоритма Apriori. Проект включает реализацию алгоритма, проведение экспериментов на реальных данных и визуализацию результатов.

## Структура проекта

```
bigdata/
├── apriori.py                    # Основная программа с алгоритмом Apriori
├── experiments.py                # Скрипт для проведения экспериментов
├── generate_report.py            # Генератор PDF отчета
├── baskets.csv                   # Набор данных (7501 транзакция)
├── experiment_results.json       # Результаты экспериментов
├── performance_vs_support.png    # График времени выполнения
├── itemsets_by_length.png        # График распределения по длине
├── total_itemsets_vs_support.png # График общего количества наборов
├── Отчет_Apriori.pdf            # Финальный отчет
└── README.md                     # Этот файл
```

## Использование

### Базовый запуск

```bash
python apriori.py <порог_поддержки> [способ_сортировки]
```

**Параметры:**
- `порог_поддержки` - минимальная поддержка в процентах (например, 5 для 5%)
- `способ_сортировки` - 'support' (по умолчанию) или 'lexicographic'

**Примеры:**

```bash
# Поиск с порогом поддержки 5%
python apriori.py 5

# Поиск с порогом 3% и лексикографической сортировкой
python apriori.py 3 lexicographic
```

### Проведение полных экспериментов

```bash
python experiments.py
```

Этот скрипт:
- Запускает алгоритм с порогами поддержки: 1%, 3%, 5%, 10%, 15%
- Сохраняет результаты в `experiment_results.json`
- Создает 3 визуализации результатов

### Генерация PDF отчета

```bash
python generate_report.py
```

Создает файл `Отчет_Apriori.pdf` с полным отчетом о результатах.

## Результаты экспериментов

| Порог поддержки | Время (сек) | Количество наборов | Макс. длина |
|-----------------|-------------|-------------------|-------------|
| 1%              | 1.0774      | 261               | 3           |
| 3%              | 0.2222      | 55                | 2           |
| 5%              | 0.1072      | 28                | 2           |
| 10%             | 0.0132      | 7                 | 1           |
| 15%             | 0.0074      | 5                 | 1           |

### Основные выводы

1. **Быстродействие**: Время выполнения экспоненциально снижается с увеличением порога поддержки (от ~1.08 сек при 1% до ~0.007 сек при 15%)

2. **Количество наборов**: При низких порогах обнаруживается значительно больше ассоциаций. При 1% найдено 261 набор, при 15% - только 5

3. **Длина наборов**: Наборы длины 2-3 товара появляются только при порогах до 5%. При 10% и выше - только одиночные товары

4. **Оптимальный порог**: Для данного набора данных рекомендуется использовать порог 3-5% для баланса между количеством найденных ассоциаций и их значимостью

## Описание алгоритма Apriori

Алгоритм Apriori работает в два этапа:

1. **Генерация частых наборов**:
   - Находит все частые 1-наборы (отдельные товары)
   - Итеративно генерирует кандидатов размера k из k-1 наборов
   - Проверяет поддержку каждого кандидата

2. **Отсечение кандидатов**:
   - Использует принцип антимонотонности: все подмножества частого набора также должны быть частыми
   - Удаляет кандидаты, не удовлетворяющие этому условию

## Формат данных

Входной файл `baskets.csv` содержит по одной транзакции на строку:
```
товар1,товар2,товар3,...
товар4,товар5,...
...
```

## Визуализации

Проект создает три типа графиков:

1. **performance_vs_support.png** - зависимость времени выполнения от порога поддержки
2. **itemsets_by_length.png** - распределение наборов по длине для разных порогов
3. **total_itemsets_vs_support.png** - общее количество найденных наборов vs порог
